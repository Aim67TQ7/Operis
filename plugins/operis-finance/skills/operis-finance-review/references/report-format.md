# Default management report

Honor any user-provided template before this default.

1. **Conclusion:** Two or three sentences stating the measured change and the
   strongest supported explanation. Label hypotheses as hypotheses.
2. **Scope:** Company, sources, fiscal comparison, currency, as-of time and whether
   each period is complete. Say when freshness is unknown.
3. **Comparison:** Current, prior and change for relevant measures. Use percentage
   points for margin differences. Mark missing/undefined values clearly.
4. **Drivers:** A short ranked table of measured contributors, with source evidence.
   Avoid claiming causal price/volume/mix drivers from totals alone.
5. **Reconciliation:** Control totals, differences, duplicate/join checks, pagination
   completeness and limitations. State whether control totals were unavailable.
6. **Review questions:** Only material questions, with suggested owner when known.
   Avoid commanding leadership or presenting a proposed action as approved.

Use compact prose and tables. Expose definitions or assumptions only when they
change interpretation. A requested Excel/PDF output needs the relevant document
or spreadsheet workflow; do not claim a file was created unless it exists.
